## 0.1.0

* Initial release of `flutter_python_ml`.
* Multi-platform support: Android, iOS, macOS, Windows, Linux, and Web.
* Direct Python script and function execution bridge (`PythonBridge`, `PythonML`).
* High-level Machine Learning model lifecycle abstraction (`PythonMLModel`).
* Embedded pure-Dart Python interpreter for zero-dependency on-device execution (`DartPythonInterpreter`).
* Multi-dimensional tensor container with math helpers (`TensorData`).
* Zero-network local process IPC engine (`LocalProcessEngine`).
* Android and iOS native platform channel integration (`PlatformChannelEngine`).
* Zero-setup mock ML engine for instant offline testing and CI (`MockPythonEngine`).
* Interactive developer UI widgets: `PythonConsoleView`, `ModelInferenceCard`, `TensorVisualizer`.
* Showcase demo models: Iris flower classification, real estate regression, NLP sentiment analysis.
